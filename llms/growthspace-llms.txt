# Growthspace

> Growthspace is a precision skill development platform for enterprise learning and talent teams. It matches individual employees and cohorts with a network of 2,800+ vetted domain experts across 65+ countries and 80+ skill sets, then runs and measures the resulting development sprints — 1:1 skill development, group skill development, workshops, internal and external mentoring, and the ExpertX on-demand expert surface.

Generated by API Evangelist on 2026-08-22 from probed evidence. Growthspace serves no llms.txt of its own (https://www.growthspace.com/llms.txt returns 404) and publishes no developer portal, so this file records what is actually reachable.

## What is machine-readable

- [Public API Management OpenAPI (JSON)](https://public-api-management-dot-growthspace-246311.oa.r.appspot.com/api/docs-json): OpenAPI 3.0.0, 12 operations across 11 paths. Served live by the service. info.title "@growthspace-engineering/public-api-management", contact gsBot@growthspace.com.
- [Public API Management OpenAPI (YAML)](https://public-api-management-dot-growthspace-246311.oa.r.appspot.com/api/docs-yaml): the same document in YAML.
- [Swagger UI](https://public-api-management-dot-growthspace-246311.oa.r.appspot.com/api/docs): the only API reference Growthspace exposes.
- [Public API scope catalogue](https://public-api-management-dot-growthspace-246311.oa.r.appspot.com/admin/scopes): answers anonymously; 11 scopes over programs, participants, workshops, company, reporting and integration, in READ and WRITE variants, plus a cross-company `joker` scope reserved for Growthspace admins.

## What is NOT available

- No developer portal, no getting-started guide, no authentication documentation, no error reference, no rate-limit documentation, no changelog.
- No client SDK in any language, in any package registry.
- No MCP server for the Growthspace API, and no A2A agent card on any host.
- No /.well-known/ document on any host, including security.txt.
- No published pricing: https://www.growthspace.com/pricing renders a contact form.
- No contract for the Public API data plane. The six resource domains named by the scope catalogue (programs, participants, workshops, company, reporting, integration) have no published OpenAPI; only the application-management surface does.
